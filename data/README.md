# Data

This folder will contains the data for all analyses:

- `plots.tsv`: forest plots data extracted from INDORES dataverse
- `coords.tsv`: forest plots coordinates extracted from INDORES dataverse used by the get_era script
- `get_era.py`: python script to retrieve corresponding ERA5-Land data
- `era.tsv`: ERA5-Land data for the three forests
- `erafrance.nc`: ERA5-Land data for the whole France on August 11th 2023 at 12pm
- `data.tsv.gz`: all assembled raw data
- `decomposition.tsv`: macrolimate and microclimate decomposition with Fourier’s transformations
- `methor_data_onf/`: macrolimate RENECOFOR weather station data

All analyses and files production can be found in the [analyses](https://sylvainschmitt.github.io/fourier/).
