# RENECOFOR weather station data

This folder will contains the RENECOFOR weather station data:

- `coord_stations_meteo_renecofor_corr.xlsx`: weather stations coordinates
- `MetHor2018.org`: weather data column names
- `MetHor20XX.txt.gz`: weather data

We thank the Office National des Forêts (ONF) and the RENECOFOR network for providing the weather station data used as macroclimate reference, and in particular Manuel Nicolas (head of the RENECOFOR network) and Sébastien Macé (in charge of the data, including the meteorological data) for their help.
